# SDI Output · DeckLink

Приймає контракт з порту `in` і відтворює відео та embedded PCM на одному фізичному SDI-порту. Відеогілка узгоджує роздільність, точну кадрову частоту, тип розгортки та піксельний формат із заданим режимом. Аудіогілка передає один interleaved PCM-банк 48 кГц із 2, 8 або 16 каналами у `S16LE` або `S32LE` зі збереженням порядку каналів. Обидві гілки використовують один зсув часових міток для поточного покоління.

| Поле | Значення |
| --- | --- |
| `persistent_id` | Сталий ідентифікатор вихідного порту з детектора DeckLink |
| `mode` | Явний режим `decklinkvideosink`, наприклад `1080p25`, `1080i50` або `1080p2997` для відповідного порту |
| `video_format` | `UYVY` за замовчуванням або `v210` |
| `playout_delay_ms` | Буфер планування відтворення 60–500 мс, за замовчуванням 100 мс |
