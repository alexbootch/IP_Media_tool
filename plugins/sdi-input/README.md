# SDI Input · DeckLink

Захоплює SDI-відео в автоматично визначеному режимі та один банк вбудованого PCM. Публікує спільний A/V-контракт на порті `out`. Кадри та аудіоблоки отримують часові мітки одного GStreamer pipeline. Після втрати сигналу або зміни caps нода відкликає старе покоління SHM.

Поля конфігурації:

| Поле | Значення |
| --- | --- |
| `persistent_id` | Сталий ідентифікатор вхідного порту з детектора DeckLink |
| `audio_channels` | Обов’язковий вибір `2`, `8` або `16` відповідно до джерела. Нода передає канали у вихідному порядку |
| `audio_format` | `S32LE` за замовчуванням або `S16LE` |
| `measure_av` | За замовчуванням вимкнено. Вимірює зсув за тестовим спалахом і імпульсом на першому каналі |
